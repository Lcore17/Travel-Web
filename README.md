# Travel Web - Anime Atlas

Anime Atlas is a responsive frontend travel website inspired by anime locations and experiences.

This project is built with HTML, CSS, and JavaScript only (no backend), and includes multiple pages with a consistent UI, mobile navigation, and interactive sections.

## Live Project Scope

- Frontend-only website
- Multi-page navigation
- Responsive layouts for desktop, tablet, and mobile
- Shared external stylesheet and script for maintainability

## Pages

- Home: `index.html`
- Destinations: `destination.html`
- Packages: `packages.html`
- Gallery: `gallery.html`
- About: `about.html`
- Contact: `contact.html`
- Login: `login.html`

## Features

- Fixed top navigation with hamburger menu on small screens
- Animated homepage sections
- Destination and package cards
- Portrait gallery layout with hover overlays
- Contact form with client-side validation
- Shared footer with social links

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

No build tools or package installation are required.

## Notes
